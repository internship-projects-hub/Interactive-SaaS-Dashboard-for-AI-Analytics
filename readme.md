# 🚀 SaaS Interactive Dashboard

A modern frontend dashboard project built to demonstrate real-world UI/UX engineering skills using HTML, CSS, and JavaScript with animations and data visualization.

---

## 👤 Author

Dilip Singh (Frontend Developer)

---

## 📌 Features

- 📊 Interactive dashboard layout (SaaS style)
- 📈 Charts using Chart.js
- 🎨 Smooth UI animations
- 🌐 3D animated background using Three.js
- 📱 Fully responsive design
- ⚡ Simulated real-time data updates

---

## 🧰 Tech Stack

HTML, CSS, JavaScript, GSAP, Chart.js, Three.js

---

## 📁 Project Structure

project/ ├── index.html ├── style.css ├── app.js ├── charts.js ├── three-bg.js └── assets/

## 🚀 Run Project

Open `index.html` directly in browser (no setup required)
